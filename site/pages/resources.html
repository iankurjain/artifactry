1. What Artifactry is, and why it exists

When you ask an AI to write a report, build a web page or draft a deck, the result usually lives inside that one chat. Close the chat, switch to a different AI, or come back next week, and it's gone or buried.

Artifactry is a library for those results. Think of it as a shared, organised filing cabinet that both you and your AI tools can open. An artifact is one saved file (a PDF, a Word document, a slide deck, a web page or an image) together with everything Artifactry knows about it: its title, tags, versions, who can see it and how it's been used.

Three things make it different from a normal file drive:

  • AI apps can use it directly. Claude, ChatGPT, Gemini and other assistants connect over MCP and can search, save and share for you.
  • Links never break. Each artifact has one permanent address that survives renames, moves and new versions.
  • You stay in control. An AI can only do what you allow, can never see more than you can, and has to ask before sharing anything outside your organization.
💡

Nothing to install. Artifactry is a hosted service. You don't download anything, run a server or set up a database. You sign in at {{APP_HOST}} and connect your AI apps with a web address.

2. Getting started: create your account

Artifactry has no passwords. You sign in with a short code sent to your email, and the same steps create your account the first time.

  1. Open {{APP_HOST}} in any browser, on your computer or phone.
  2. Type your email address and choose Send code.
  3. Open the email from Artifactry and type the 6-digit code on the next screen.
  4. You're in. A personal workspace is created for you automatically, and you are its admin.
ℹ️

Codes expire after 10 minutes and work once. If one doesn't arrive, check spam, then ask for a new one after the short cooldown (about 30 seconds). Your sign-in lasts 30 days on that device; Log out ends it immediately.

A quick tour

  • Library lists everything you can open, newest first. Filter by type and change the sort.
  • Search looks inside your files as well as their names.
  • Add uploads a file or connects an AI app.
  • Profile holds your connected AI apps, tags, active shares and the in-app guide.
  • Workspace (the icon in the left rail on desktop) manages the current workspace's name, logo, members and invitations.

On your phone

The same app works in any phone browser. The menu moves to a bar along the bottom of the screen; everything else works the same way.

3. Your first artifact

  1. Choose Add, then Upload a file, and pick a file from your device.
  2. Give it a clear title. Check the workspace it belongs in and, if you like, put it in a collection.
  3. Choose Upload. Artifactry checks the file's real type, records a checksum, scans it, and pulls out its text so it's searchable.
  4. Open the artifact. You'll see suggested tags based on its content: accept the good ones, delete the rest, or add your own.

To update it later, upload a new file to the same artifact rather than a new one. That creates version 2, keeps version 1 downloadable, and the link stays the same. Open Version history on the artifact to see every version or restore an older one.

Web pages (HTML)

HTML artifacts open as a live preview right on the artifact page. Safe Preview renders HTML and CSS but runs no JavaScript. Interactive Preview runs scripts in an isolated sandbox with network access blocked. See Limits and file types for how to switch.

Collections

A collection groups related artifacts, like "Q4 launch" or "Board prep". An artifact sits in one collection at a time. Pick one when you upload, choose Change on the artifact page, or move many at once from the Library.

  1. In the Library, choose Select.
  2. Tick the artifacts you want, then choose Set collection in the bar at the bottom.
  3. Pick a collection (or New collection, or No collection) and choose Apply.

Owners and Admins also see Delete in that bar. Deleting always asks you to confirm and is permanent: the files, their text and their shares are removed.

Finding things

Search looks at titles, tags and the text inside your files. Results show the type, workspace and tags so you can tell similar files apart.

💡

Only confirmed tags are searchable. A suggestion becomes part of your vocabulary once you accept it.

4. Workspaces and teams (share mode)

A workspace is a separate space with its own artifacts, tags and members, a bit like a project folder with its own guest list. Switching workspaces never mixes two projects together.

Switch with the workspace button at the top of Home (on desktop the current workspace also shows under the logo in the left rail).

TypeWho it's forWhat you get
PersonalJust youName, logo, time zone, date format, invitations
SharedA teamEverything in Personal, plus a team directory, roles (Owner, Admin, Member, Guest and custom tiers) and an optional custom share URL

Turning on team mode

  1. Open Workspace and go to Invitations.
  2. Enter a teammate's email and choose a role.
  3. The first invitation from a personal workspace asks you to confirm it becomes a shared workspace. Confirm, and the invite is sent.

Managing a shared workspace

Open Workspace to change the name, logo, time zone and date format, and (in shared workspaces) to see the team, set roles and control invitations.

Teams: reusable audiences

A team is a named group such as "Board prep" or "Finance reviews". Share with the name instead of typing emails each time. Membership stays live: someone added to the team later gets access to what was already shared with it, and removing someone takes it away.

⚠️

If two of your teams share a name, Artifactry asks which one you mean instead of guessing. Confidential documents are no place for a coin flip.

5. Sharing

Nothing is shared by default. When you share, you choose who and what they may do.

AudienceHow the recipient gets in
A team or workspaceSigns in to Artifactry as usual
Specific email addressesEnters a code sent to that address
An email domainProves an address on that domain with a code
Anyone with the linkOpens the link, no sign-in

For every share you can set an expiry, allow view only or download, and revoke it at any time, which ends access immediately. Recipients see only the item you shared, never the rest of your library.

Share a file

  1. Open the artifact and choose Share.
  2. Choose who can access it. For Specific people, type their email addresses.
  3. Pick when it expires, then choose Create link.
  4. Copy the link straight away. It is shown once; if you lose it, revoke the share and make a new one.

Every share you've made is listed under Profile → Active shares, where you can check expiries and revoke.

6. Connecting AI apps

AI apps reach Artifactry through one web address, its MCP endpoint:

Most apps use OAuth sign-in: you paste the address, a window opens, you sign in to Artifactry and choose Allow. There's no token to copy, and access refreshes itself. Step-by-step guides for each app are in the MCP Integration tab.

In the app, choose Connect an AI tool on Home (or Profile → Set up Claude, ChatGPT, Cursor and more). Copy the server URL, then open the tool you use for its steps.

7. Personal access tokens

Some tools can't do a browser sign-in: scripts, scheduled jobs, or an MCP client without OAuth. For those, create a personal access token, a long secret string the tool sends with every request.

  1. In the app, open Profile and scroll to Connected AI apps.
  2. Choose the app you're connecting (or Other MCP client for scripts) and choose Connect.
  3. Tick only the permissions it needs. A read-only script needs just artifact.read.
  4. Copy the token straight away. It is shown once and stored only as a hash, so it can't be shown again.

Permissions (scopes)

ScopeAllows
artifact.readSearch and open artifacts
artifact.writeSave, add versions, upload in parts, change tags
artifact.shareCreate and revoke shares
workspace.readList your workspaces
team.readList teams you can share with
tags.readList available tags
analytics.readRead usage analytics
⚠️

Treat a token like a password. Don't paste it into chats, commit it to Git or share it. Pasted tokens don't expire, so if one leaks, open Profile → Connected AI apps and Disconnect it; it stops working at once.

8. Using Artifactry from the command line

There's no separate CLI to install. The MCP endpoint is ordinary JSON over HTTPS, so any HTTP tool can call it with a personal token. These examples use curl, which comes with macOS, Linux and Windows 10+.

Step 1: store your token

Terminal (macOS / Linux)
export ARTIFACTRY_TOKEN="paste-your-token-here"
PowerShell (Windows)
$env:ARTIFACTRY_TOKEN = "paste-your-token-here"

Step 2: list the tools (no token needed)

Terminal
curl -s {{MCP_URL}}

This returns the tool list and the permission each one needs. It's a quick way to check Artifactry is reachable.

Step 3: search your library

Terminal
curl -s {{MCP_URL}} \
  -H "Authorization: Bearer $ARTIFACTRY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call",
       "params":{"name":"search","arguments":{"query":"launch plan","limit":5}}}'

List workspaces

Terminal
curl -s {{MCP_URL}} \
  -H "Authorization: Bearer $ARTIFACTRY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call",
       "params":{"name":"list_workspaces","arguments":{}}}'

Save a page

Terminal
curl -s {{MCP_URL}} \
  -H "Authorization: Bearer $ARTIFACTRY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":3,"method":"tools/call",
       "params":{"name":"save","arguments":{
         "file":"hello.html",
         "title":"Hello from curl",
         "content":"<!DOCTYPE html><html><body><h1>Hello</h1></body></html>"}}}'

Read one artifact

Terminal
curl -s {{MCP_URL}} \
  -H "Authorization: Bearer $ARTIFACTRY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":4,"method":"tools/call",
       "params":{"name":"get","arguments":{"artifact":"{{APP_ORIGIN}}/a/YOUR_ARTIFACT_ID"}}}'
💡

Pipe the output through jq to make it readable: add | jq to the end of any command. On Windows PowerShell, Invoke-RestMethod works too.

9. How agents use artifacts across sessions

AI chats forget. Each new conversation starts blank. Artifactry is the long-term memory they can share: one session saves, a later session (even in a different AI app) finds and builds on it.

A typical week

  1. Monday, in Claude: "Draft a launch plan and save it to Artifactry." Claude calls save and gets back a permanent link.
  2. Wednesday, in ChatGPT: "Find the launch plan in Artifactry and add a pricing section." ChatGPT calls search, reads it with get, then saves the update with create_version. Same link, now version 2.
  3. Friday, in Cursor: "Pull the launch plan from Artifactry and turn the checklist into tickets." The coding agent reads the latest version.
  4. Any time: "Share the launch plan with Board prep for a week." One share call, inside your organization, no prompt needed.

Every artifact records which AI created or changed it, so "which AI did what, on whose behalf" always has an answer. You see it as Made by Claude, Made by Cursor and so on, and you can filter search by it.

💡

Tell the AI to reuse. Phrases like "update the existing one" or "save as a new version" steer it to create_version instead of making duplicates.

10. Handing work between AI tools

A handoff is a short note plus a few artifacts that one AI tool leaves for the next one. Claude finishes the research, hands it to Cursor to build, and Cursor hands the code and spec on to Gemini for the deck. Nothing is copied and pasted, and every step stays in your library.

Leave a handoff

  1. In the tool that did the work, say: "Save this to Artifactry and hand it off to Cursor with a brief: build the API from this spec." The AI calls save, then handoff.
  2. It replies with a link (…/h/hof_…) and a pickup line, a sentence you paste into the next tool.
  3. You can also start one in the app: open an artifact and choose Hand off to another AI tool.

Pick it up

  1. Open the next tool (it must be connected to Artifactry too).
  2. Paste the pickup line, for example "Open my Artifactry handoff hof_… and do what its brief asks." If you don't have it, say "Pick up my latest Artifactry handoff."
  3. The tool calls get_handoff, reads the brief and every file in full (code and Markdown come back exactly as written), and gets to work. The handoff shows Picked up by Cursor in the app.

Built from: lineage

When an AI saves something it made from other artifacts, Artifactry records Built from links. The AI can name its sources (derived_from); if it doesn't, Artifactry links what that same connection read in the last two hours. Open any artifact to see what it was built from and what it was used in, and remove a link that's wrong.

Projects

Mark a collection as a project (in Collections, choose Use as a project) and your AI tools can list it and save straight into it: "Save this to the Q4 launch project."

💡

Handoffs follow your access. The next tool only sees the artifacts you can read. Anything you can't read is left out, never revealed.

11. Troubleshooting

My sign-in code never arrived.

Check the address for typos and look in spam or promotions. Wait for the cooldown and request a new code. Codes expire after 10 minutes.

My upload failed.

The usual causes are a file over 25 MB, an unsupported type, or a file whose contents don't match its extension (for example a video renamed to .pdf). All three are refused on purpose.

My AI app says it isn't authorised, or returns a 401.

The connection may have been disconnected, replaced by a newer one, or it lacks the permission that action needs (for example artifact.share for sharing). Remove and re-add the connector in your AI app, or create a new token with the right scopes.

My AI doesn't see a tool, or uses an old version of it.

AI apps cache the tool list. Refresh or reconnect the Artifactry connector in the app's settings and start a new chat.

The AI says it shared something, but nobody can open it.

For public links and outside emails, the first call only returns a confirmation request. Approve it in the chat so the AI can finish the share. Also check the share hasn't expired or been revoked.

I can't find a file I uploaded.

Make sure you're in the right workspace, then search a word you know is inside it. Scanned PDFs are pictures of text, so search those by title or tags instead.

The AI couldn't save a very long page or a large file.

Ask it to "send it in parts". It will use upload_part to send the file in pieces and then save it. In ChatGPT, attaching the file to the chat lets it hand the file over directly.

12. Best practices

  • Grant the least access that works. A research assistant may only need artifact.read. Add artifact.share only for apps you trust to share.
  • One workspace per project or client. It keeps search results focused and makes access easy to reason about.
  • Use teams, not email lists. Sharing with "Board prep" stays correct as people join and leave.
  • Set expiries on outside shares. A link that ends on its own can't be forgotten.
  • Version, don't duplicate. Updating an artifact keeps its history and its link.
  • Curate tags. Accept good suggestions and reject the noise; confirmed tags make search sharper for everyone.
  • Review connected apps now and then. Disconnect anything you no longer use from Profile.
  • Give titles a human could search. "Q3 board deck v2 (final)" beats "deck-final-final.pptx".

13. Limits and file types

  • Types: PDF, DOCX, PPTX, HTML, PNG, JPG, JPEG, BMP, GIF and WEBP, plus notes, data and code as plain text: Markdown, TXT, CSV, JSON, YAML and common source files (JS, TS, Python, Go, Rust, Java, SQL and more).
  • Text and code files: up to 10 MB, shown as plain text and returned to AI tools exactly as written.
  • Size: up to 25 MB per file.
  • HTML preview: new HTML uploads start in Interactive Preview, which runs scripts in an isolated sandbox with network access blocked. Untick it when you upload, or switch per artifact, for Safe Preview, which renders HTML and CSS but runs no JavaScript.
  • Scanned PDFs have no text layer, so they're findable by title, tags and dates rather than their words.
  • Thumbnails aren't generated yet; files show a type badge.
  • Beta: features may change while Artifactry is in beta. Have an idea? Request a feature.

Before you start

MCP (Model Context Protocol) is a common language that lets AI apps use outside tools. Connecting Artifactry over MCP gives your AI the Find, Save and Share tools from the User Guide.

ChatGPTWeb and desktop apps ClaudeDesktop, web and Claude Code GeminiGemini CLI and Enterprise

Every app uses the same address:

{{MCP_URL}}

You'll need

  • An Artifactry account. Create one free if you haven't.
  • The AI app you want to connect, signed in.
  • About two minutes.
🔑

How sign-in works. When you add the address, the AI app opens an Artifactry page. Sign in with your email code, review what the app is asking for, and choose Allow. The app gets a key that refreshes itself, and you can revoke it any time in Profile → Connected AI apps.

ChatGPT

Prerequisites

  • ChatGPT on the web (chatgpt.com) or the desktop app.
  • A Plus, Pro, Business, Enterprise or Edu plan. Custom connectors need Developer mode, which isn't available on the free plan. On Business and Enterprise, a workspace admin may need to allow it.

Setup

  1. Open Settings → Security and login (on some plans Settings → Apps & Connectors → Advanced) and turn on Developer mode.
  2. Go to Settings → Apps & Connectors and choose Create.
  3. Fill in the form:
    Connector details
    Name:            Artifactry
Description:     My Artifactry library: search, save and share artifacts
MCP Server URL:  {{MCP_URL}}
Authentication:  OAuth
  4. Tick that you trust the app and choose Create.
  5. A window opens on {{APP_HOST}}. Sign in with your email code and choose Allow.
  6. Start a new chat. Open the + menu, choose Developer mode and switch on Artifactry.

Authentication

OAuth handles everything; you never copy a token. If your company blocks OAuth connectors, ask your ChatGPT admin to approve Artifactry.

Try it

Say this in ChatGPT
List my Artifactry workspaces.

Write a one-page summary of this chat as HTML and save it to Artifactry.

Find my launch plan in Artifactry and add a risks section as a new version.

Behind the scenes, ChatGPT calls a tool like this:

Tool call
save({
  "file": "chat-summary.html",
  "title": "Chat summary",
  "content": "<!DOCTYPE html><html>…</html>"
})

Common pitfalls

  • No "Create" button: Developer mode is off, or your plan or admin doesn't allow custom connectors.
  • Artifactry isn't used in chat: switch it on for that chat from the + → Developer mode menu, or name it: "use Artifactry to…".
  • Custom GPTs: GPT "Actions" are a different system and can't use MCP connectors. Use a normal chat with Developer mode.
  • Files you attach: ChatGPT can hand attached files straight to Artifactry. Say "save the file I attached to Artifactry".

Claude (Desktop, web and mobile)

Prerequisites

  • A Claude account at claude.ai. Custom connectors work on every plan; the Free plan allows a limited number.
  • On Team and Enterprise plans, an owner adds the connector once for the organization, then each person connects their own account.

Setup

  1. In Claude Desktop or at claude.ai, open Settings → Connectors.
  2. Choose Add custom connector.
  3. Enter the details:
    Connector details
    Name:               Artifactry
Remote MCP server URL:  {{MCP_URL}}
    Leave the advanced OAuth Client ID and Secret fields empty. Artifactry registers Claude automatically.
  4. Choose Add, then Connect. Sign in to Artifactry in the window that opens and choose Allow.
  5. In a chat, open the tools menu (the sliders icon) and make sure Artifactry is switched on.

Connectors added at claude.ai also appear in Claude Desktop and the mobile apps.

Prefer a config file? (Claude Desktop)

If you can't use custom connectors, Claude Desktop can reach Artifactry through the small open-source mcp-remote bridge. You need Node.js 18 or newer installed.

  1. In Claude Desktop, open Settings → Developer → Edit Config. This opens claude_desktop_config.json.
  2. Paste this in (merge with anything already there) and save:
    claude_desktop_config.json
    {
  "mcpServers": {
    "artifactry": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "{{MCP_URL}}"]
    }
  }
}
  3. Quit Claude Desktop completely and reopen it. A browser window asks you to sign in to Artifactry and Allow.

Try it

Say this in Claude
Which Artifactry workspaces do I have?

Turn this conversation into a polished HTML brief and save it to Artifactry.

Search Artifactry for the Q3 finance deck and share it with the Board prep team for 7 days.
Tool call
share({
  "artifact": "{{APP_ORIGIN}}/a/01J9Y…",
  "team": "Board prep",
  "permission": "view",
  "expires_in_days": 7
})

Common pitfalls

  • "Couldn't connect": check the URL ends in /api/v1/mcp with no trailing spaces.
  • Claude asks before every call: that's Claude's per-tool approval. Lookups are marked read-only; you can choose "Always allow" for tools you trust.
  • New tools don't show up: open Settings → Connectors, disconnect and reconnect Artifactry, then start a new chat.
  • Config file ignored: the JSON must be valid (watch for missing commas) and Claude Desktop must be fully quit, not just closed.

Claude Code

Prerequisites

  • Claude Code installed and signed in (run claude in a terminal to check).

Setup with OAuth (recommended)

  1. Add the server. --scope user makes it available in every project:
    Terminal
    claude mcp add --transport http --scope user artifactry {{MCP_URL}}
  2. Start Claude Code and type /mcp. Choose artifactry → Authenticate, sign in in the browser and choose Allow.

Setup with a personal token

For CI or machines without a browser, create a token and pass it as a header:

Terminal
claude mcp add --transport http artifactry {{MCP_URL}} \
  --header "Authorization: Bearer $ARTIFACTRY_TOKEN"

Or share it with your team in a project .mcp.json (the token stays in each person's environment, not the file):

.mcp.json
{
  "mcpServers": {
    "artifactry": {
      "type": "http",
      "url": "{{MCP_URL}}",
      "headers": { "Authorization": "Bearer ${ARTIFACTRY_TOKEN}" }
    }
  }
}

Try it

Say this in Claude Code
Save docs/architecture.html to Artifactry in the Engineering workspace.

Find the latest API design doc in Artifactry and check this branch against it.

Common pitfalls

  • Shows "needs authentication" in /mcp: choose Authenticate and finish the browser sign-in.
  • Token header not working: make sure ARTIFACTRY_TOKEN is exported in the shell that starts claude.
  • Check status any time: claude mcp list.

Gemini

  • Server shows as disconnected: run /mcp auth artifactry again.

Check it works

  1. Is Artifactry reachable? Open {{MCP_URL}} in a browser. You should see a JSON list of tools.
  2. Is your AI connected? Ask it: "List my Artifactry workspaces." You should get your workspace names back.
  3. Can it save? Ask: "Save a short test note to Artifactry called Connection test." It should reply with a link starting {{APP_ORIGIN}}/a/.
  4. Does it show up? Open {{APP_HOST}}. The note is at the top of your Library, and Profile → Connected AI apps shows the app as connected.
